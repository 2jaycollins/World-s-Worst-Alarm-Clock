## Video

GitHub will **not** play an `.mp4` committed to the repo. Two ways round it:

**1. The drag-and-drop trick (easiest).** Open the repo on github.com, go to the
Issues tab, start a new issue, and drag the video file into the comment box.
Wait for the upload to finish — GitHub inserts a line like
`https://github.com/user-attachments/assets/abc123...`. Copy that line into the
README on its own line and it renders as a playable video. Close the issue
without submitting; the uploaded file stays hosted.

**2. Link to YouTube with a thumbnail.**

    [![Watch the demo](docs/video-thumbnail.jpg)](https://youtu.be/YOUR_VIDEO_ID)
